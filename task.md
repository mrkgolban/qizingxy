# Техническое задание
## Численное исследование одномерной квантовой XY-модели

## 1. Постановка задачи

Рассматривается одномерная цепочка из \(N\) взаимодействующих спинов \(1/2\) во внешнем магнитном поле.

Гамильтониан анизотропной квантовой XY-модели имеет вид

\[
H =
-J\sum_{i=1}^{N-1}
\left[
(1+\gamma)\sigma_i^x\sigma_{i+1}^x
+
(1-\gamma)\sigma_i^y\sigma_{i+1}^y
\right]
-h\sum_{i=1}^{N}\sigma_i^z,
\]

где

- \(N\) — число спинов в цепочке;
- \(J\) — константа взаимодействия между соседними спинами;
- \(h\) — внешнее магнитное поле;
- \(\gamma\) — параметр анизотропии;
- \(\sigma_i^{x,y,z}\) — матрицы Паули, действующие на \(i\)-й спин.

На первом этапе используются **открытые граничные условия**.

Размерность пространства состояний системы равна

\[
D=2^N.
\]

Таким образом, для каждого значения параметров необходимо построить матрицу Гамильтониана размера

\[
2^N\times2^N
\]

и найти её собственные значения и собственные векторы численно.

---

# 2. Частный случай: квантовая модель Изинга

Особый интерес представляет случай

\[
\gamma=1.
\]

Тогда гамильтониан принимает вид

\[
H =
-2J\sum_{i=1}^{N-1}
\sigma_i^x\sigma_{i+1}^x
-h\sum_{i=1}^{N}\sigma_i^z.
\]

С точностью до выбора нормировки \(J\) это одномерная квантовая модель Изинга в поперечном магнитном поле.

Для этой модели в термодинамическом пределе существует квантовый фазовый переход при

\[
\frac{h}{J}=1
\]

при соответствующем выборе нормировки параметров.

В конечной системе настоящего фазового перехода нет, поэтому необходимо исследовать его **конечно-размерные проявления**.

---

# 3. Цель численного исследования

Основная цель проекта — **численно исследовать энергетический спектр и физические свойства одномерной квантовой XY-модели и сравнить полученные результаты с известным аналитическим решением модели.**

В частности, необходимо исследовать зависимость физических характеристик системы от:

\[
\frac{h}{J},
\]

\[
\gamma,
\]

и размера системы

\[
N.
\]

Особое внимание необходимо уделить области квантового фазового перехода и исследованию того, как его проявления изменяются при увеличении \(N\).

# 4. Основные задачи

Для достижения поставленной цели необходимо:

1. Реализовать представление квантовых состояний цепочки из \(N\) спинов.
2. Реализовать операторы Паули \(\sigma_x,\sigma_y,\sigma_z\).
3. Построить матрицу Гамильтониана XY-модели.
4. Использовать битовое представление базисных состояний для эффективного построения матрицы.
5. Численно найти собственные значения и собственные векторы Гамильтониана.
6. Вычислить основные физические наблюдаемые.
7. Исследовать зависимость наблюдаемых от \(h/J\).
8. Повторить расчёты для различных значений \(N\).
9. Реализовать аналитическое решение модели.
10. Сравнить численные и аналитические результаты.
11. Исследовать влияние конечного размера системы на результаты.
12. Визуализировать полученные зависимости.

# 5. Численное представление состояний

В качестве базиса используется вычислительный базис

\[
|s_1s_2\dots s_N\rangle,
\qquad
s_i\in\{0,1\}.
\]

Для программной реализации состояние представляется целым числом

\[
0,\ldots,2^N-1.
\]

Например, при \(N=3\):

\[
\begin{aligned}
0 &\leftrightarrow |000\rangle,\\
1 &\leftrightarrow |001\rangle,\\
2 &\leftrightarrow |010\rangle,\\
3 &\leftrightarrow |011\rangle,\\
4 &\leftrightarrow |100\rangle,\\
5 &\leftrightarrow |101\rangle,\\
6 &\leftrightarrow |110\rangle,\\
7 &\leftrightarrow |111\rangle.
\end{aligned}
\]

В программной реализации индексы спинов считаются от

\[
0,\ldots,N-1.
\]

Таким образом, индекс спина совпадает с индексом соответствующего бита.

# 6. Реализация операторов Паули

Односпиновые матрицы Паули:

\[
\sigma_x=
\begin{pmatrix}
0&1\\
1&0
\end{pmatrix},
\]

\[
\sigma_y=
\begin{pmatrix}
0&-i\\
i&0
\end{pmatrix},
\]

\[
\sigma_z=
\begin{pmatrix}
1&0\\
0&-1
\end{pmatrix}.
\]

Явное построение больших матриц через произведения Кронекера желательно не использовать.

Операторы должны реализовываться непосредственно через битовые операции.

### Оператор \(\sigma_i^z\)

Он не изменяет состояние:

\[
\sigma_i^z|s\rangle
=
(-1)^{s_i}|s\rangle.
\]

Следовательно, он даёт вклад только в диагональные элементы матрицы.

Для получения \(i\)-го бита:

```cpp
int bit = (state >> i) & 1;
